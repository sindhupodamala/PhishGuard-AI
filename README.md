# PhishGuard-AI
AI-based phishing email and suspicious URL detection system using Python and Flask.
🛡️ PhishGuard AI

AI-Based Phishing Email and Suspicious URL Detection System

📌 Project Overview

PhishGuard AI is a cybersecurity project designed to identify phishing emails and suspicious website URLs. It helps users recognize potential online threats through email analysis and URL risk assessment.

✨ Features

- Phishing email detection using Machine Learning.
- Suspicious URL detection using security rules.
- Threat level classification: High, Medium and Low.
- Risk score calculation.
- Detection history tracking.
- Dashboard with statistics and charts.
- Security alerts for suspicious detections.

🛠️ Technologies Used

- Python
- Flask
- Machine Learning
- Scikit-learn
- HTML
- CSS
- JavaScript
- Chart.js
- SQLite

⚙️ How to Run

1. Install Python.
2. Install the required dependencies.
3. Open the project folder in VS Code.
4. Run:

python app.py

5. Open your browser and visit:

http://127.0.0.1:5000/
